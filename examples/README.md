# Examples

This directory contains example ALPS documents.

## `test-sample.alps.json`

This file is an illustrative ALPS edge-case sample. It is **not** used by the automated test suite.

It contains intentionally empty fields in descriptors to demonstrate various valid descriptor configurations for reference and parser testing:

- `id`
- `type`
- `format`
- `href`
- `rt`

These empty values are intentional and serve as edge cases for testing purposes.
